# CinaVault Server Premium Edition iOS

CinaVault Premium iOS v1.0.3 Pre-Beta Build 103. The release workflow publishes a
clearly labeled, unsigned iOS Simulator TEST application with SHA-256 checksum
and installation notes. Physical-device and App Store distribution still
requires Apple signing credentials and provisioning.

Windows pairing: this iOS build pairs to Windows CinaVault-Premium
v2.1.7-beta-3 (main commit 7bd0b75c); see docs/platform-parity.json and
Settings > Platform parity for what beta-3 carries over and what remains
explicitly left behind. The iOS bundle identity is unchanged by that pairing.
